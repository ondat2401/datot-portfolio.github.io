🔄 Sync / Export

Export → JSON

Download data từ Supabase thành file JSON. Commit vào repo để portfolio hiển thị.

Import ← JSON

Upload file JSON lên Supabase khi bạn sửa code trực tiếp.

Cách sync
  • Admin page → Supabase → Export JSON → commit repo
  • Sửa code → Import JSON lên admin → Supabase cập nhật
  • Portfolio luôn đọc file JSON tĩnh (nhanh, không phụ thuộc DB)
